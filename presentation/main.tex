\section{Motivation}

\begin{frame}{Motivation}
    Examples where it does not / it does matter how things are done by AI agents.
\end{frame}

\begin{frame}{Symbolic AI + Searching}
    \begin{itemize}
        \item On many occasions, \emph{how} an agent achieves its goals matters at least as much as \emph{whether} it does so or not.
        \item Such cases can be naturally encoded as search problems, where the agent searches for an optimal path, $p$, from a starting state, $s$, to a goal state, $p$.
        \item In ensuring a faithful implementation of instructions, design guarantees are key to avoid common modern AI issues, like overfitting / inability to generalize, hallucinations, and so on.
        \item Thus, symbolic AI approaches, offering formal guarantees, are a good candidate to undertake this task.
    \end{itemize}
\end{frame}
