\section{Motivation}

\begin{frame}{Motivation}
    \begin{itemize}[<+->]
    	\item Consider the following examples of AI agents:
    	\begin{itemize}[<+->]
    		\item Agent $A$ provides machine translation services.
    		\item Agent $B$ provides ``study at home'' support for students.
    		\item Agent $C$ serves as a cognitive substitute of a therapist for their clients.
    	\end{itemize}
    	\item While agent $A$ is typically focused on \emph{what} should be achieved, agents $B$ and, mostly, $C$, should also put emphasis on \emph{how} their goal is reached.
    	\item Hence, faithful knowledge transfer arises as a natural prerequisite for tasks where an agent's behavior does matter.
    \end{itemize}
\end{frame}

\begin{frame}{Optimization as a Search Problem}
    \begin{itemize}[<+->]
        \item Such cases can be naturally encoded as search problems in a state space, where the agent searches for an optimal path, $p$, from a starting state, $s$, to a goal state, $g$.
        \item Thus, the \emph{what} aspect corresponds to the goal state, $g$, the agent has to reach.
        \item Similarly, the \emph{why} aspect corresponds to the shape of the optimal path, $p$.
        \item Essentially, by applying restrictions on the shape of that path, the agent is searching for a tuple, $(p,g)$, such that $p$ connects its starting state, $s$, with the end state, $g$, while $p$ adheres to a set of constraints, $\constraints$.
    \end{itemize}
\end{frame}

		\item Exception-based knowledge representation.
		\item Transparent interaction.
		\item Efficient reasoning.

		\item Empirically verified learning efficiency and efficacy.
	\end{itemize}

\section{Empirical Setting}

\begin{frame}{Search Coaching}
    \begin{itemize}[<+->]
        \item In this work, we use Machine Coaching to gradually instill knowledge to an agent about both \emph{what} and \emph{how} to look for a goal state $g$.
        \item We explore the highly structured problem of sorting a randomly permuted list of $n$ integers by gradually providing advice, based on some common sorting algorithms.
        \item Our goal is to explore:
        \begin{itemize}[<+->]
	        \item whether the agent learns how to sort (the \emph{what});
        	\item whether the agent sorts faithfully to its coach's policy (the \emph{how}), and;
        	\item how efficient the learning process is.
        \end{itemize}
    \end{itemize}
\end{frame}

\begin{frame}{Definitions}
    \begin{itemize}[<+->]
    	\item A \emph{coaching step} is a single advice exchange between the coach and the agent.
        \item \emph{Advice coverage} is defined to be the percentage of information included in a rule's body compared to state size, $n$.
        \item \emph{Memory} in our context corresponds to the ability of the agent to recall previous from potentially structurally different settings.
        \item \emph{Coaching conformity} is the extent to which the agent's optimal path $p$ corresponds to what the coaching policy would yield as an optimal path within a coaching session.
    \end{itemize}
\end{frame}

\section{Discussion \& Future Work}

\begin{frame}{Discussion \& Future Work}
    \begin{itemize}[<+->]
    	\item In our exploration, effectively coaching an agent to perform a certain sorting task using purely symbolic means has proven to be feasible.
    	\item Moreover, we have demonstrated that under the coaching paradigm, one can fine tune the agent's behavioral conformity by properly adjusting the coaching protocol.
    	\item Next steps in this exploration might include but not restrict to:
    	\begin{itemize}[<+->]
    		\item the exploration of other toy examples of higher complexity;
    		\item comparison with other Machine Learning approaches, e.g., Reinforcement Learning;
    		\item application in realistic settings.
    	\end{itemize}
    \end{itemize}
\end{frame}
